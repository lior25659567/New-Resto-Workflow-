Goal:
Refactor the application into two distinct stages: Pre-Processing (Pre-Entry) and Main Application (Interactive Analysis), with a clear transition and preserved state.

✅ Part 1 — Pre-Entry Stage (Preparation & Configuration)
Create a dedicated pre-entry stage that runs after loading the .ply files and before entering the main app.
This stage should include:


Mesh Loading & Alignment

Load .ply files
Allow manual or assisted alignment between meshes



Prep Labeling

Enable interactive labeling of the preparation region (vertex painting / segmentation)



Cross-Section Setup

Allow the user to define one or more cross-sections
Save the selected default cross-section



Undercut Insertion Path Selection

Allow the user to define and interactively adjust the insertion direction vector
Provide immediate visual feedback (e.g., undercut preview)



Zoom to Prep

Enable zoom-to-selected-prep functionality and persist camera position




✅ State Persistence
Create a PreState object that stores:

aligned geometries
prepMask / labeled vertices
insertion vector
selected cross-section(s)
camera position / target
scale normalization (if applied)


✅ Transition

👉 “Go to App”

Initialize Part 2 (Main App) using this state
